# 赛题与实现对照

2026 年全国大学生电子设计竞赛（广西赛区）**F 题：李萨如图形显示控制装置**。

赛题原文 PDF 属组委会文件，不放进仓库；下面是要点摘要 + **每条要求落在代码哪里**。

---

## 1. 任务

信号源输出一路正弦（1 kHz ~ 100 kHz，步进 100 Hz），同时送示波器 X 轴与本装置。
装置处理后在 Y 轴输出一路信号，控制屏幕上李萨如图形的形状。
摄像头对准示波器屏幕，图像回传到装置，构成自动模式。
示波器 X、Y 通道灵敏度固定 0.5 V/div。

---

## 3. 三个可调量，覆盖前四题

题面看着复杂，其实前四题只对应三个可调量：

| 题 | 可调量 | 代码位置 |
|---|---|---|
| 一 | 倍频数 = 1，相位 = 0° | `output_mode` / `dds_phase_target_mdeg` |
| 二 | 相位 = 90° | 同上，PE2 切换 |
| 三 | 倍频数 = 2 | 同上，PE3 切换 |
| 四 | 四档幅度 | PB4~PB7，纯硬件 |

这也是这套代码的结构来源：`signal_app.c` 里所有逻辑都围绕这三个量，
而不是按题目写成四套流程。改题目只要改这三个量。

## 4. 关键技术指标达成情况

| 指标 | 题面要求 | 本装置 | 说明 |
|---|---|---|---|
| 输入频段 | 1 k ~ 100 kHz，步进 100 Hz | 1 k ~ 100 kHz，四档采样率自动切换 | 100 kHz 档每帧 1024 点，1.024 ms |
| 测频分辨 | 100 Hz 步进 | 插值后约 ±0.05 格，1 MHz 档 ±48 Hz | 1024 点 FFT + 三谱线插值 |
| 幅度误差 | ≤ 0.2 div | 正交投影拟合测幅，四档电阻 1% 精度 | 见 `docs/hardware.md` 5.2 |
| 相位锁定 | 图形不转 | 落后稳差 < 0.1°，约 25 ms 判定锁定 | 5 ms 节拍 × 连续 5 帧 |
| 控制时间（第五题） | ≤ 10 s | 取决于扫描策略，Q2/Q3 复用 Q1 的频率 | 见 `K230/README.md` 版本演进 |
| 稳定时间 | ≥ 5 s | 锁定后持续保持，靠 PI 环抵消频差漂移 | 无累计漂移，只有噪声抖动 |

## 5. 题目给的四个「不能做」

赛题说明里有几条限制，直接影响设计，这里单独记一下：

1. **示波器灵敏度不能改**（0.5 V/div 固定）→ 幅度只能靠装置自己调，所以必须有四档增益。
2. **信号源频率不能在装置里设置**（步进 100 Hz 也不许设）→ 装置必须**自己测出**输入频率。
   这是整个 FFT 测频环节存在的理由。
3. **摄像头不得拍到信号源操作面板**→ 必须用挡板遮住示波器面板。
4. **第 5 题测试时信号源与装置之间不得有任何电气耦合**→ 装置在视觉模式下
   只能靠摄像头看屏幕，不能靠测输入信号。所以 `SignalApp_Suspend` 会停掉采样、
   让 AD9834 保持复位，彻底变成「盲控」。
   主循环里 `AppMode_EnterVision()` 后面那句 `continue` 的作用是：进入视觉模式
   这一轮不再往下走（模式标志刚改，本轮已没有正常模式的活要干），下一轮直接落进
   `VisionSlave_Process()`，省掉一次无意义的分支判断。

## 6. 赛后回看：哪些地方可以更好

| 问题 | 现状 | 改进方向 |
|---|---|---|
| 换档丢帧 | 停表→改时基→开表，中间至少丢一帧，约 25 ms 未锁定 | 双缓冲时基切换，或预先算好两套 ARR 直接热切换 |
| 混叠卡错档 | 判据只看峰是否在窗口内 | 加谱峰质量判据（峰值/次峰比），而不是靠 5 秒重探兜底 |
| 频率分辨率 | 被 1024 点锁死，1 MHz 档 ±48 Hz | 加到 2048 点 + 重叠窗，或改用相位差测频 |
| 幅度开环 | 四档靠硬件电阻，误差靠电阻精度 | 加可编程增益级进软件闭环（需要硬件改版） |
| 失败即停机 | 任何 HAL 失败进 `Error_Handler` 死循环 | 现场这么写是对的（快速暴露接线问题），产品化要改成降级重试 |
